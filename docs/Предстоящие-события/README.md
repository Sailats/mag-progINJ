# 📅 Предстоящие события

[← На главную](../../README.md) · [Начало работы](../Начало-работы.md) · [Окружение разработки](../Окружение-разработки.md)

Учебный план следующего этапа проекта на **январь и февраль 2027 года**. Периоды служат примером планирования и могут быть скорректированы по заданиям преподавателя.

## Порядок чтения

1. **[События января](События-Января.md)** — подготовка требований, окружения и структуры проекта.
2. **[События февраля](События-Февраля.md)** — прототип, проверка сценариев и подготовка демонстрации.

| Месяц | Основной результат этапа |
| --- | --- |
| [Январь](События-Января.md) | Согласованные требования и подготовленный план реализации |
| [Февраль](События-Февраля.md) | Прототип и результаты проверки его основных сценариев |

## Порядок страниц

В оглавлении и ссылках между страницами январь расположен перед февралём. Учебный файл [`.order`](.order) фиксирует тот же порядок именами файлов без расширений:

```text
События-Января
События-Февраля
```

При добавлении нового месяца обновите оглавление, ссылки переходов и `.order`.
