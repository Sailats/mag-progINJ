**Период:** январь 2027 года. **Цель этапа:** определить требования и подготовить основу для разработки учебного приложения.

## План работ

| Период | Мероприятие | Ожидаемый результат |
| --- | --- | --- |
| 11–17 января | Выбрать тему и описать пользователей приложения | Краткое описание предметной области и основного сценария |
| 18–24 января | Сформулировать требования и проверить окружение | Перечень функций и готовые инструменты разработки |
| 25–31 января | Уточнить архитектуру и разделить работу на задачи | Схема компонентов и план первой версии |

## Окружение для работы

1. **GitHub** — репозиторий, документация и совместная работа.
2. **Git** — локальная история изменений и синхронизация.
3. **Markdown-редактор** — подготовка страниц; можно использовать редактор GitHub или Visual Studio Code.

Подготовка инструментов описана в [окружении разработки](../Окружение-разработки.md). Язык приложения и дополнительные зависимости выбираются после согласования требований.

## Критерии завершения этапа

- [ ] Определены пользователи и основной сценарий приложения.
- [ ] Описаны функциональные требования.
- [ ] Участники проверили рабочее окружение.
- [ ] Обновлена схема компонентов.
- [ ] Подготовлен план первой версии приложения.
